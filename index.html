PROJECT BRIEF · 30 SECONDS

The question

X-rays reveal what the eye cannot. How does a machine turn invisible radiation into a measurable decision?

The physics

Photons cross the body; dense tissue absorbs more, so the detector records a whiter pixel.

The method

Our own transparent algorithm: local contrast → threshold → shape rules. No black box; each step can be adjusted.

The insight

Every detector trades sensitivity against false alarms. Tune it yourself and see why.

Physics: why bones are white

Each dot is an X-ray photon. Thicker or denser (density) material absorbs more; the detector turns what arrives into a pixel. Drag thickness.

When the algorithm fails (and why)

Every detector makes mistakes. Press a button to reproduce each one in the Explorer.

FALSE ALARM

Flags something that is not there

Healthy image, T=24. A faint bump is just brighter than T. The algorithm measures brightness and shape only; it cannot know the bump is noise. Fix: raise T.

MISSED SPOT

Real spot not found

T=44. The real spots are only about 30–40 brighter than their surroundings, so they fall below the cut-off. Fix: lower T.

MERGED REGION

T too low, spot disappears

T=8. So many pixels pass that the spot touches a neighbouring rib and they become one long region, which the shape rule rejects. Lower is not always better.

Go deeper

Why compare with neighbours, not just brightness?

Bone is brighter than any spot, so "bright = bad" fails. A spot matters when it is brighter than its own surroundings.

Why subtract two averages?

Small average (5×5) kills noise. Big average (R) is the slow body shading. Small − big is a band-pass filter: keeps only spot-sized features.

Why does it still make mistakes?

Ribs crossing lungs and noise look bright. Shape rules remove many, not all. Real systems use far more features, and doctors decide.

Key terms · tap any highlighted word to jump here

One-line definitions of every mechanism.

PHYSICS

Photon

One packet of X-ray energy. Millions cross the body every second.

PHYSICS

Density

How tightly matter is packed. Bone is dense; lung is mostly air.

PHYSICS

Detector

The sensor behind the body. It counts arriving photons; fewer photons = whiter pixel.

DEEPER

False alarm

A flagged region that is not a real spot. Lowering T creates more of them.

PHYSICS

Absorption

Matter takes X-ray energy. Denser or thicker = more absorbed: I = I₀·e^(−μx). Less reaches the detector → whiter pixel.

DATA

Pixel

One tiny square, stored as a number: 0 black … 255 white. The computer only sees numbers.

DATA

Noise

Random speckle from the detector. Averaging nearby pixels cancels it.

STEP A–B

Local average

Mean brightness of a window around a pixel. Our estimate of "normal here". Window size = R.

STEP C

Local contrast

diff = smooth − background. Positive = brighter than its surroundings.

STEP D

Threshold T

Cut-off. diff > T → candidate pixel. Low T finds more, but also more false alarms.

STEP E

Blob

Touching candidate pixels grouped into one region (flood fill).

STEP E

Shape rules

Spots are round, ribs are long arcs. aspect = long side ÷ short side. Aspect > 1.8 or low fill → rejected.

STEP 0

Region of interest

Only the dark, air-filled lung area is analysed (two biggest dark regions). Bone and heart would cause false alarms.

DEEPER

Sensitivity vs false alarms

Catching every real spot raises false alarms. Every detector balances both.

DEEPER

Band-pass filter

Keeps features of one size range: drops tiny noise and huge slow shading.

TRUST

Explainability

The algorithm shows why: brightness, size, shape evidence per region. No hidden decision.

How this project is built (honest version)

What is real, what is simulated, what is tested.

ONE ALGORITHM

JavaScript + Python

The website runs core.js in your browser. xray_core.py is the same steps written in Python. They do not run each other; instead an automated test checks that both give the same answers on the demo images.

SIMULATION

Not a diagnosis

All images are synthetic, drawn by code with spots we placed ourselves. We have not tested real patient X-rays. This is a teaching simulation of image-processing steps, not a medical tool.

TESTED

Key tests

Healthy image, weak contrast, fake signals and JS = Python. One test shows an honest limit: very faint spots are missed.
